# Back-End Engineering Job Simulation at Lyft

## About the Project

This repository documents my work on the Back-End Engineering Job Simulation at Lyft, focusing on software architecture, code refactoring, design patterns, unit testing, and test-driven development (TDD).

The project involved working with an existing codebase, designing a reorganized architecture, implementing the updated design, and improving code quality through automated testing.

## Tasks & Implementation

### 1. Software Architecture

- Cloned and explored an existing codebase to understand its structure and functionality.
- Analyzed existing classes and their relationships.
- Designed a UML class diagram to represent the proposed architecture and component interactions.

### 2. Code Refactoring

- Refactored the existing codebase to align with the redesigned architecture.
- Applied the Factory Pattern to centralize and simplify object creation.
- Applied the Method Pattern to organize behavior and improve code structure.

### 3. Unit Testing

- Developed unit tests for the refactored implementation.
- Validated individual components and their expected behavior.
- Used automated tests to help identify regressions and improve code reliability.

### 4. Test-Driven Development (TDD)

- Added new functionality using a test-driven development workflow.
- Wrote tests to define expected behavior before implementing the corresponding functionality.
- Iteratively refined the implementation to satisfy the tests.
